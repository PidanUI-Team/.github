# PidanUI 团队介绍

PidanUI 是一个非官方的粉丝创作项目，旨在为 Windows / Linux 桌面打造《蛋仔派对》风格的美化主题包。

团队继承了 EggyUI 的技术积累与美学方向，在经历项目重组后，以更清晰的组织方式继续推进开发。PidanUI 并非从零开始的新项目，而是 EggyUI 在新名称下的延续。

## 发展历程与团队变迁

PidanUI 的起点可以追溯到早期的 EggyUI 项目。EggyUI 于 2024 年 4 月起步，7 月 22 日发布 1.0 版本并迅速获得关注。项目在发展过程中经历了一些调整，团队结构也在不同阶段发生了变化。

进入 2026 年后，项目以新的组织形式继续推进。原有的技术路线、组件架构与美化方案被整合到 PidanUI 中，团队在总结经验的基础上，对治理方式与开发流程做了进一步优化。目前，PidanUI 作为 EggyUI 的延续，继续推进蛋仔风格 Windows / Linux 桌面美化的开发与维护。

> [!NOTE]
> PidanUI 项目目前正在持续开发中，欢迎关注后续版本发布。
